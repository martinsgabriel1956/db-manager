## Priority Issues

1. **[P1] Atalhos globais disparam por trás da confirmação de prod.** `App.tsx:109` só bloqueia com `[role='dialog']`, mas `ConfirmDialog.tsx:54` usa `role="alertdialog"`. Verificado: Ctrl+B recolheu a lateral sob o diálogo; Ctrl+W empilhou "Descartar alterações?" sobre "Confirmar execução"; Esc depois deixou o foco fora do alertdialog. Ctrl+Q, Ctrl+K e Ctrl+Tab ficam expostos igual. Quebra o único momento que o produto promete proteger. Fix: seletor `[role='dialog'],[role='alertdialog']` + teste de Ctrl+W com a confirmação aberta. Comando: /impeccable harden
2. **[P2] NULL + Enter grava `''`.** `editText` devolve "" para NULL (`staged.ts:29`) e `stageUpdate` só considera "inalterado" se `value === null` quando o original é NULL. Em dev/staging não há confirmação, então um Enter perdido escreve string vazia (jsonb pode recusar). Viola "o valor gravado". Fix: não commitar quando o texto não mudou desde o início da edição; placeholder `NULL` no input; atalho de teclado para NULL no editor inline. Comando: /impeccable harden
3. **[P2] Finais de escrita em prod desiguais.** Tabela: "1 alteração salva" (`useTableEditing.ts:87`). Editor: recibo com conexão, PROD e "Ver no histórico". Fix: reutilizar o recibo do editor na barra da tabela para salvamentos confirmados/prod, e a linha "nada rodou" ao cancelar. Comando: /impeccable polish
4. **[P2] Paleta com consulta vazia é uma lista sem estrutura.** 24 linhas misturando quatro tipos, "Nova query SQL" repetida por conexão, "Cache editar conexão" em 3º. Fix: grupos com títulos em legend (Tabelas e coleções / Bancos Redis / Conexões / Ações), "Nova query SQL" única para a conexão ativa, ~5 itens por grupo até digitar. Comando: /impeccable distill
5. **[P3] Rótulo de aba truncado duas vezes.** "Postgres pro… ER publ…" (`TabBar.tsx:283/355`, `max-w-60` + `max-w-28`). Fix: com pouco espaço, trocar o nome da conexão pelo código da engine + tag de ambiente antes de truncar o rótulo. Comando: /impeccable layout
